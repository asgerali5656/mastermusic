# भोजपुरिया गुलाम (Bhojpuriya Ghulam Radio)

Non-stop 24/7 all-time-hit and trending Bhojpuri songs jukebox radio featuring Pawan Singh, Khesari Lal Yadav, Dinesh Lal Yadav 'Nirahua', and more.

## Development & Local Access

To run the application locally:

```sh
npm install
npm run dev
```

The application will be accessible on your local network at `http://localhost:8080/` and via your local IP address.
